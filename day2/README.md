# 1-Week Course — Day 2: Codex Engineering Patterns

Day 2 flows from a context engineering deep dive into prompt engineering practice, then a lab/capstone spike, then an overview of context frameworks (including BMAD’s out-of-the-box prompts).

You will restart from fresh Codex sessions throughout.

## Outcomes

- Explain key context engineering concepts and common failure modes.
- Create a four‑prompt sequence (fresh sessions) that moves from story → review → dev prompt → code review.
- Run a small lab or capstone spike using your prompt sequence and collect evidence.
- Compare context engineering frameworks and see how BMAD maps to the same prompt phases.
