# Module 3 — Data Processing & Observability

**Timebox:** 45–60 minutes

## Overview

Leverage Codex to trace silver outputs into curated gold products, combining business-question refinement, metric design, and masking guidance with disciplined execution tracking. The goal is a consumable dataset plus an observability log that proves how the results were produced and how sensitive fields stay protected.

## Process

- Define the target business questions and gold-layer consumption pattern, then co-design the required metrics/measures with Codex.
- Apply Codex-suggested masking or access patterns to sensitive silver fields before exposing them downstream.
- Execute the SQL or scripts step by step, keeping query history notes or screenshots that map each run to an expected outcome.
- Capture the curated gold outputs (tables, views, dashboards) alongside the metric calculations and any validation queries.
- Draft lightweight monitoring guidance—query history checks, warehouse usage, alert thresholds—so future runs can be verified quickly.
