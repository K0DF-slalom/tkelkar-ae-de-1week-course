# Module 1 — Synthetic Data Pipelines

**Timebox:** 45–60 minutes

## Overview

Use Codex to translate a real-world scenario into a safe synthetic dataset, clarify requirements with structured prompts, and design an ingest-to-transform pipeline that is observable from the start. You will combine profiling, documentation, and metric planning.

## Process

- Prime Codex with the scenario, constraints, and success criteria using structured prompt patterns before touching the data.
- Source or generate a non-sensitive synthetic dataset that mirrors the target domain, and document how it was produced.
- Ask Codex to scaffold an ingest ➜ transform flow, then iterate until the steps, tooling, and file formats are explicit.
- Run profiling (distribution checks, distinct counts, outliers) and capture the insights that influence downstream transformations.
- Layer in data-quality expectations, monitoring hooks, and at least one KPI calculation, then package the findings alongside the pipeline notes.
