# Module 3 — Capstone Spike

**Timebox:** 45–90 minutes

## Overview

In this module, you will create your own mini-project in Codex from plan to finish, using the four-prompt sequence and practicing the workflow.

## Process

- Choose a small task or a capstone‑style idea (e.g., “add a data‑quality check + report”).
    Capstone options from later in the course [here](../day4/README.md#concrete-scope-examples-pick-one-or-adapt). If choosing one of the capstone options, limit the scope to a task you can complete in 45 minutes.
- Run the four‑prompt sequence end‑to‑end.
- Capture evidence: prompt text, outputs, and verification results.
