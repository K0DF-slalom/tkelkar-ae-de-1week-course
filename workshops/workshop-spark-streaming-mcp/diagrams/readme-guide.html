Mission

Build a local streaming platform where synthetic stock trades flow through Spark, land in Postgres, and are queryable via an MCP server.

2 - Prerequisites
Local setup
  • Docker (Colima on macOS or native Linux)
  • Python 3.12+
  • Codex CLI installed and authenticated
Project scaffolding
  • Folder layout: src data scripts
  • Centralized settings in config.py
  • Shared Python requirements for MCP and generators
3 - Parts 1-2 (Scaffolding + Containers)
Part 1
  • Create structure and config
  • Define dependencies in requirements.txt
  • Document core variables early
Part 2
  • Single Docker image with Spark + Java
  • Compose services: postgres, spark-master, spark-worker, mcp-server
  • Init SQL for tables, views, indexes
Build and verify with docker-compose before moving on. Stable infra is the foundation for the rest.
4 - Parts 3-4 (Streaming + Generators)
Streaming processor
  • Explicit schema for streaming JSON
  • Three sources: socket, file, rate
  • Enrichment + windowed aggregations
  • Write to Postgres via foreachBatch
Generators
  • Socket generator for live trades
  • File generator writing Parquet batches
  • Atomic file writes to avoid partial reads
