Quick Start Guide

Fastest path to validate the pipeline end-to-end

1 - Quick map
Recommended path
  • Rate source first
  • Socket source second
  • Query Postgres
  • Use MCP tools
Follow the steps in order to avoid setup drift.
Environment
Colima (macOS)
Docker + Compose
Spark 4.0.1
Postgres 16
2 - Prerequisites check
Verify tools
  • colima version
  • docker --version
  • docker-compose version
Why this matters

Confirm local tooling before you build containers to avoid ambiguous errors.

3 - Steps 1-3 (Start + Build + Verify)
Step 1
Start Colima

Allocate at least 4 CPUs and 8GB RAM for Spark.

colima start --cpu 4 --memory 8 --disk 60
Step 2
Build and start

Build the unified image and start all containers.

docker-compose up -d --build
Step 3
Verify services

Check logs and confirm Postgres is ready.

docker-compose exec postgres psql -U sparkuser -d sparkdb -c "SELECT 'Database ready!' as status;"
4 - Steps 4-6 (Run streaming)
Step 4
Rate source

Fastest sanity check with no external generator.

docker-compose exec spark-master spark-submit --master spark://spark-master:7077 --driver-class-path /opt/spark/jars/postgresql-42.7.1.jar --conf spark.executor.extraClassPath=/opt/spark/jars/postgresql-42.7.1.jar /app/src/stream_processor.py rate
Step 5
Socket source

Use two terminals: generator and streaming job.

docker-compose exec spark-master python3 /app/src/stock_data_generator.py --rate 5
Step 6
File source (optional)

File streaming is currently unstable. Use rate or socket if stuck.

5 - Steps 7-8 (Query + MCP)
Query Postgres
  • SELECT recent trades
  • COUNT total trades
  • Check aggregations
  • Group by symbol
MCP server
  • Tail logs: docker-compose logs -f mcp-server
  • Endpoint: http://localhost:3333/sse
  • Tools: latest_prices, recent_trades, window_aggregates, symbol_summary
6 - Steps 9-10 (Monitor + Cleanup)
Web UI
  • Spark Master UI: http://localhost:8080
  • Spark App UI: http://localhost:4040
Cleanup
  • Stop jobs and generators
  • docker-compose down
  • docker-compose down -v
  • colima stop
7 - Troubleshooting
Common issues
  • Cannot connect to Docker daemon
  • Port already in use
  • Out of memory
  • No data in database
  • Driver class not found
Fast checks
  • colima status
  • docker-compose logs spark-master
  • docker-compose exec spark-master ping postgres
