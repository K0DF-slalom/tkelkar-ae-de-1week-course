# Module 4 — Context Frameworks Overview

**Timebox:** 45–60 minutes

## Overview

In this module, you will learn about some of the most up-to-date frameworks for developing processes with GenAI models.

## Process

- Open `ia-codex-bench` and skim each framework branch:
  - OpenSpec (spec-first workflow): <https://bitbucket.org/slalom-consulting/ia-codex-bench/src/main/Open_Spec/>
  - PRP (Product Requirement Prompt): <https://bitbucket.org/slalom-consulting/ia-codex-bench/src/main/PRP-framework/>
  - Spec‑Kit (spec‑driven dev): <https://bitbucket.org/slalom-consulting/ia-codex-bench/src/main/spec-kit/>
  - BMAD (multi‑agent workflows): <https://bitbucket.org/slalom-consulting/ia-codex-bench/src/main/bmad-method/>
- Identify how each framework encodes: needs, constraints, plan, and verification.
