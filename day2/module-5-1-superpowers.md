# Module 5.1 — Superpowers Introduction

**Timebox:** 30 minutes

## Overview

In this module, you will get introduced to the Superpowers framework and how it structures agent work through reusable skills.

Reference repository: [Superpowers on GitHub](https://github.com/obra/superpowers)

## Why It Matters

Superpowers gives you lightweight workflows for common development tasks such as brainstorming, planning, debugging, test-driven development, and verification. Instead of relying on one long prompt, you use focused skills to shape how the model approaches each phase of the work.

## Process

Start by identifying the type of task you are doing, then pick the matching skill or workflow. For example:

- Use brainstorming before designing a new feature or changing behavior.
- Use writing-plans before implementing a multi-step task.
- Use systematic-debugging when you hit a failure or unexpected behavior.
- Use verification-before-completion before claiming the work is done.

The goal is to make the model's process more explicit, repeatable, and easier to review as your work gets more complex.
