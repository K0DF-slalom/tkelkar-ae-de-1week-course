# Module 5 — BMAD Out‑of‑the‑Box Prompts

**Timebox:** 30–45 minutes

## Overview

In this module, you will go deeper into the BMAD framework and use it in your prompts.

## Process

BMAD includes agent prompts that line up with the story → dev → QA flow.

Example commands:

```text
*agent po *validate-story-draft docs/stories/story-1.1-data-pipeline.md
*agent dev *develop-story docs/stories/story-1.1-data-pipeline.md
*agent qa *validate docs/stories/story-1.1-data-pipeline.md
```

If your BMAD branch uses a different story path, update the file path accordingly.
